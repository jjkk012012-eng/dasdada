공장용 STEP 견적 계산기 - 99MB 이하 Logic Pro

목적
- 공장 1곳이 고객에게 받은 STP/STEP 어셈블리 파일로 내부 견적을 빠르게 산출하는 웹앱입니다.
- 어셈블리/서브어셈블리는 견적 대상에서 제외하고 말단 파트만 견적표에 표시합니다.
- 자동 분석값을 먼저 채우고, 공장이 공법/재질/수량/탭/절곡/마진을 수정하면 즉시 재계산됩니다.

절곡 기준
- 단순히 90도 모서리라고 절곡으로 잡지 않습니다.
- 같은 두께가 유지되는 얇은 판재형 부품이어야 합니다.
- BEND/BENT/FOLD/FLANGE/L_BRACKET/U_BRACKET/절곡 등 휨/플랜지 힌트가 있어야 자동 절곡 후보를 생성합니다.
- 그냥 SIDE_PANEL, COVER 같은 얇은 판은 판금 후보지만 절곡 횟수는 0으로 두고 공장이 직접 입력합니다.
- PIPE/TUBE/각관/파이프/튜브는 구매품 우선이며 절곡으로 잡지 않습니다.

CNC 기준
- 구매품, 프로파일, 선반품, 판금/절곡 후보를 먼저 제외합니다.
- 남은 부품 중 덩어리형 절삭가공품, 포켓/홈/단차/탭/홀 후보가 있는 경우 CNC/MCT로 추천합니다.

주의
- 이 버전은 브라우저 정적 배포용입니다.
- 실제 STEP 형상을 100% 정확히 분석하려면 OpenCascade/OCCT WASM 파서를 붙여야 합니다.
- 현재 코드는 STEP 텍스트 엔티티와 파트명 기반 고급 휴리스틱 + 공장 수정 구조입니다.

실행
1. 압축을 풉니다.
2. index.html을 브라우저로 엽니다.
3. fetch 보안 문제가 있으면 폴더에서 `python -m http.server 8080` 실행 후 http://localhost:8080 접속합니다.
